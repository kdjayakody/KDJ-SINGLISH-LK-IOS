## Description

**Full Description (4000 char limit):**

Type in English letters and get beautiful Sinhala instantly — right from your keyboard.

Singlish LK is a custom keyboard that converts your Singlish typing to Sinhala script in real-time. Type "kohomada" and see "කොහොමද" appear instantly. Perfect for Sinhala speakers who type in English but want to communicate in their native language.

**KEY FEATURES:**
• Real-time Singlish to Sinhala conversion
• Custom keyboard with Sinhala phonetic labels on every key
• Smart word suggestions that learn your typing patterns
• One-tap language toggle between English and Sinhala
• Share converted text to WhatsApp and any app
• Recent phrases for quick copy-paste access
• Beautiful dark theme interface
• No internet connection required — works 100% offline

**HOW TO USE:**
1. Install the app and enable the Singlish LK keyboard in Settings
2. Allow Full Access for complete functionality
3. Switch to the Singlish LK keyboard using the globe icon 🌐
4. Start typing in English — Sinhala appears as you type

**TYPING EXAMPLES:**
• kohomada → කොහොමද
• oyata kohomada → ඔයාට කොහොමද
• mama hodai → මම හොඳයි
• giyamu → ගියමු
• banna → බන්නා
• adarei → ආදරෙයි

Singlish LK respects your privacy. All processing happens on-device. No data is collected or transmitted.

## Archive & Upload Steps (in Xcode)

1. Open `Singlish Pro.xcodeproj` in Xcode
2. Select "Any iOS Device (arm64)" as destination
3. Select your **Development Team** in Signing & Capabilities
4. Product → Archive
5. In Organizer, select the archive → Distribute App
6. Choose "App Store Connect" → Upload
7. Fill in compliance questions (encryption: Yes for HTTPS, but exempt for standard encryption)
8. Submit for review

## Export Compliance Note

The app uses standard iOS frameworks (StoreKit for review prompts, UIKit, SwiftUI). No custom encryption is used. Answer "Yes" to encryption question and select "Exempt" or "Standard encryption" during submission.
